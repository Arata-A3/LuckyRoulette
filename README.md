# LuckyRoulette

自分で設定した項目の中からルーレットで1つを選ぶアプリ。ブラウザで動く Web アプリ（HTML/CSS/JavaScript）で、GitHub Pages で公開する。

## 機能

### ルーレット
- 設定した項目からルーレットで1つ選ぶ
- 項目ごとに「当たりやすさ（重み）」を設定でき、マスの大きさも重みに合わせて変わる
- 当たりの項目を設定でき、当たったら虹色に光る

### 項目リスト
- リストを名前付きで複数保存し、切り替えられる（例: 「お昼ごはん」「掃除当番」）
- 「出た項目を除外」モード: 一度選ばれた項目を次の回から外す（リセットで元に戻す）

### 色
- 全体のテーマ（配色セット）を選ぶと、各マスに自動で配色される
- 項目ごとに色を指定して上書きもできる

### やり直し対策・履歴
- 抽選のやり直し自体はできるが、すべての結果が履歴に残る（何回目の抽選かが分かる）
- 毎回、自動生成のシード値をルーレットの下に薄く表示する
  - 例: `#0007 · 2026-11-11 14:32 · K7Q2-9XF3`（リストでの通し番号・日時・シード値）
  - スクリーンショットで結果を見せるとき、やり直したかどうかが通し番号で分かる
- 履歴はリストごとに保存し、一覧で見られる

## 保存
- 設定・履歴はブラウザ（localStorage）に保存する
- 簡易的な対策なので、ブラウザのデータを消したり別の端末を使ったりすると、通し番号は引き継がれない

## 使い方
- `index.html` をブラウザで開く（インストール不要）
- 真ん中の「回す」ボタン、または Space / Enter キーで回す
- 「項目」タブで項目の追加・名前・色・出やすさ（1〜100）・当たり（★）を設定する
- 「設定」タブでテーマと「出た項目を除外」を切り替える
- シード値から結果が決まる（同じシード値・同じ項目なら同じ結果）

## ファイル
- `index.html`: アプリ本体（HTML・CSS・JavaScript）
- `icon.svg` / `apple-touch-icon.png` / `og-image.png`: アイコンとリンクプレビュー用の画像
