# LuckyRoulette

自分で設定した項目の中からルーレットで1つを選ぶアプリ。ブラウザで動く Web アプリ（HTML/CSS/JavaScript）で、GitHub Pages で公開する。

## 機能

### ルーレット
- 設定した項目からルーレットで1つ選ぶ
- 項目ごとに「出やすさ（1〜100）」を設定でき、マスの大きさも出やすさに合わせて変わる
  - 「− / ＋」で変える（長押しで続けて変わる）。数字を押して直接入力もできる
- 各項目の名前の下に、出る確率を % と項目の色のバーで表示する
- 当たりの項目を設定でき、当たったら虹色に光る
- 全画面モード（ルーレットの下の ⤢）: ルーレットだけを大きく表示する。会議や配信で見せながら回すとき用。Esc か右上のボタンで戻る

### まとめて抽選
- ルーレットの下の「まとめて」から使う
- いくつか選ぶ: 出やすさに合わせて、重複なしで N 個選ぶ（当番決めなど）
- チームに分ける: 全員をランダムに N チームに振り分ける（出やすさは使わない。人数の差は 1 人以内）
- 結果は履歴に残り、通常の抽選と同じように通し番号・シード値・検証が付く

### 項目リスト
- リストを名前付きで複数保存し、切り替えられる（例: 「お昼ごはん」「掃除当番」）
  - 上部の「＋」で新しいリスト。ひな形（コイントス、サイコロ、数字 1〜10、曜日、じゃんけん、はい・いいえ、方角）から作れる
  - 「⋯」メニューで共有・名前の変更・削除
- 「出た項目を除外」モード: 一度選ばれた項目を次の回から外す（リセットで元に戻す）
- 項目は左端の点々をドラッグして並べ替えられる
- 改行や「、」で区切って貼り付けると、まとめて追加できる
- 削除した項目は「元に戻す」ボタンで戻せる

### 共有
- 「⋯」→「このリストを共有」で、リストの中身（名前・出やすさ・色・当たり）を詰めたリンクを作る。スマホは共有シート、PC はリンクのコピー
  - 中身はリンクの `#share=` の後ろにだけ入っていて、サーバーには送られない
- リンクを開くと「追加しますか？」と聞かれ、新しいリストとして追加される
- iPhone のホーム画面のアプリは Safari とデータが別なので、「⋯」→「共有リンクから追加」にリンクを貼り付けて読み込む

### 演出
- 当たりのときは紙吹雪が舞い、当たったマスが 3 秒ほど色を変えたあと虹色で止まる
- 回転中は、マスの境目を通るたびに針が跳ねる
- 回転の速さを「はやい（2.5 秒）」「ふつう（4.8 秒）」「じっくり（8 秒）」から選べる
- 「視差効果を減らす」設定の端末では、紙吹雪や光る動きを止める

### 色・見た目
- 全体のテーマ（配色セット）を選ぶと、各マスに自動で配色される
- 項目ごとに色を指定して上書きもできる
  - 色のマスを押すと色選びパネルが開き、「最近使った色」「ほかの項目と同じ色」「テーマの色」「ほかの色（端末の色選び）」から選べる。「自動に戻す」でテーマの配色に戻る
  - 最近使った色は 8 色まで保存する
- 画面の明るさを「端末に合わせる」「ライト」「ダーク」から選べる（設定タブ）

### やり直し対策・履歴
- 抽選のやり直し自体はできるが、すべての結果が履歴に残る（何回目の抽選かが分かる）
- 毎回、自動生成のシード値をルーレットの下に薄く表示する
  - 例: `#0007 · 通算123 · 2026-11-11 14:32 · K7Q2-9XF3`（リストでの通し番号・すべてのリストを合わせた通し番号・日時・シード値）
  - 「通算」はリストを消して作り直しても戻らない
  - スクリーンショットで結果を見せるとき、やり直したかどうかが通し番号で分かる
- 履歴はリストごとに保存し、一覧で見られる（日付ごとにまとめ、項目の色・当たりの印・番号・時刻・シード値を表示）
- 履歴の「検証」で、記録したシード値とそのときの候補（名前と出やすさ）から結果を計算し直し、記録と一致するか確かめられる
- 「コピー」で、`【お昼ごはん】#0007 · 2026-11-11 14:32 · K7Q2-9XF3 → お寿司（★当たり）` の形でコピーできる
- 同じブラウザでタブを複数開いても、通し番号が重ならないよう最新の内容を読み直す

## 保存とバックアップ
- 設定・履歴はブラウザ（localStorage）に保存する
- 設定タブの「バックアップを保存」で、すべてのデータを JSON ファイルに書き出す（スマホは共有シートの「ファイルに保存」など）。「バックアップから戻す」で読み込むと、今のデータと置き換わる
- 機種変更やブラウザのデータ削除で消えるので、ときどきバックアップしておく

## 使い方
- 公開ページを開く（インストール不要）
- 真ん中の「回す」ボタン、または Space / Enter キーで回す
- 「項目」タブで項目の追加・名前・色・出やすさ・当たり（★）を設定する
- 「設定」タブでテーマ・明るさ・回転の速さ・「出た項目を除外」・バックアップを扱う
- シード値から結果が決まる（同じシード値・同じ候補なら同じ結果）
- スマホでは公開ページを開き、Android（Chrome）はメニューの「アプリをインストール」/「ホーム画面に追加」、iPhone（Safari）は共有ボタンの「ホーム画面に追加」でアプリとして入れられる。一度開けばオフラインでも使える
  - ホーム画面に追加したアプリとして開くと、裏でフォント全体（約 4.8MB）を保存し、オフラインでもどの文字も丸ゴシックで表示できる。ブラウザで見るだけのときは、表示した文字の分しか読み込まない
- サービスワーカーは `file://` では動かないので、手元で試すときは `python -m http.server` などで配信して開く

## テスト
```
node tests/run.mjs            # すべて（20 秒ほど）
node tests/run.mjs 共有 色     # 名前に含まれる語で絞り込み
```
- Node 22 以上と Google Chrome が必要（Chrome の場所が違うときは環境変数 `CHROME_PATH`）
- リポジトリを小さな HTTP サーバーで配信し、ヘッドレス Chrome を操作して、スマホ幅・PC 幅で確かめる
- 主な内容: 横のはみ出し（320/360/390px）、canvas の縦横、項目行のそろい、− / ＋、色選び、抽選と検証、まとめて抽選、ひな形、共有リンク、バックアップ、タブ切り替えの位置、明るさ、全画面、壊れたセーブ、フォントの保存とオフライン
- 直したら必ず流す。失敗したら NG の行に理由が出る

## バージョン
- 画面の一番下に薄く `v2.0.0` のように表示する
- 機能を変えたら `js/app.js` の `APP_VERSION` を上げる

## ファイル
- `index.html`: 画面の骨組み（HTML）。明るさの設定を描画前に当てる小さなスクリプトだけ head に置く
- `css/style.css`: 見た目
- `js/app.js`: アプリの動き（ふつうの script。関数や `state` はページ全体から見える）
- `sw.js`: オフラインでも開けるようにするサービスワーカー（ページは通信できるときは常に最新を読み込む。フォントは保存した分を使う）。ファイルを増やしたら `FILES` に足し、`CACHE` の番号を上げる
- `manifest.webmanifest` / `icon-192.png` / `icon-512.png` / `icon-maskable-512.png`: ホーム画面に追加（PWA）するための設定とアイコン
- `icon.svg` / `apple-touch-icon.png` / `og-image.png`: アイコンとリンクプレビュー用の画像
- `lib/fonts/`: 丸ゴシックの Zen Maru Gothic（太さ 500 と 700）。Google Fonts から取得し、文字の範囲ごとに分かれていて、使う文字の分だけ読み込まれる。ライセンスは SIL Open Font License 1.1（`lib/fonts/zen-maru-gothic/OFL.txt`）
- `tests/run.mjs`: 自動テスト
