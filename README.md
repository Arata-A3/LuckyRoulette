# LuckyRoulette

自分で設定した項目の中からルーレットで1つを選ぶアプリ。ブラウザで動く Web アプリ（HTML/CSS/JavaScript）で、GitHub Pages で公開する。

## 機能

### ルーレット
- 設定した項目からルーレットで1つ選ぶ
- 項目ごとに「当たりやすさ（重み）」を設定でき、マスの大きさも重みに合わせて変わる
- 各項目の名前の下に、出る確率を % と項目の色のバーで表示する
- 当たりの項目を設定でき、当たったら虹色に光る

### 項目リスト
- リストを名前付きで複数保存し、切り替えられる（例: 「お昼ごはん」「掃除当番」）
  - 上部の「＋」で新しいリスト、「⋯」メニューで名前の変更・削除
- 「出た項目を除外」モード: 一度選ばれた項目を次の回から外す（リセットで元に戻す）
- 項目は左端の点々をドラッグして並べ替えられる
- 改行や「、」で区切って貼り付けると、まとめて追加できる
- 削除した項目は「元に戻す」ボタンで戻せる

### 演出
- 当たりのときは紙吹雪が舞い、当たったマスが 3 秒ほど色を変えたあと虹色で止まる
- 回転中は、マスの境目を通るたびに針が跳ねる
- 回転の速さを「はやい（2.5 秒）」「ふつう（4.8 秒）」「じっくり（8 秒）」から選べる
- 「視差効果を減らす」設定の端末では、紙吹雪や光る動きを止める

### 色
- 全体のテーマ（配色セット）を選ぶと、各マスに自動で配色される
- 項目ごとに色を指定して上書きもできる
  - 色のマスを押すと色選びパネルが開き、「最近使った色」「ほかの項目と同じ色」「テーマの色」「ほかの色（端末の色選び）」から選べる。「自動に戻す」でテーマの配色に戻る
  - 最近使った色は 8 色まで保存する

### やり直し対策・履歴
- 抽選のやり直し自体はできるが、すべての結果が履歴に残る（何回目の抽選かが分かる）
- 毎回、自動生成のシード値をルーレットの下に薄く表示する
  - 例: `#0007 · 通算123 · 2026-11-11 14:32 · K7Q2-9XF3`（リストでの通し番号・すべてのリストを合わせた通し番号・日時・シード値）
  - 「通算」はリストを消して作り直しても戻らない
  - スクリーンショットで結果を見せるとき、やり直したかどうかが通し番号で分かる
- 履歴はリストごとに保存し、一覧で見られる（日付ごとにまとめ、項目の色・当たりの印・番号・時刻・シード値を表示）
- 履歴の「検証」で、記録したシード値とそのときの候補（名前と出やすさ）から結果を計算し直し、記録と一致するか確かめられる
- 「結果をコピー」で、`【お昼ごはん】#0007 · 2026-11-11 14:32 · K7Q2-9XF3 → お寿司（★当たり）` の形でコピーできる
- 同じブラウザでタブを複数開いても、通し番号が重ならないよう最新の内容を読み直す

## 保存
- 設定・履歴はブラウザ（localStorage）に保存する
- 簡易的な対策なので、ブラウザのデータを消したり別の端末を使ったりすると、通し番号は引き継がれない

## 使い方
- `index.html` をブラウザで開く（インストール不要）
- 真ん中の「回す」ボタン、または Space / Enter キーで回す
- 「項目」タブで項目の追加・名前・色・出やすさ（1〜100）・当たり（★）を設定する
- 「設定」タブでテーマと「出た項目を除外」を切り替える
- シード値から結果が決まる（同じシード値・同じ候補なら同じ結果）
- スマホでは公開ページを開き、Android（Chrome）はメニューの「アプリをインストール」/「ホーム画面に追加」、iPhone（Safari）は共有ボタンの「ホーム画面に追加」でアプリとして入れられる。一度開けばオフラインでも使える

## バージョン
- 画面の一番下に薄く `v1.5.0` のように表示する
- 機能を変えたら `index.html` の `APP_VERSION` を上げる

## ファイル
- `index.html`: アプリ本体（HTML・CSS・JavaScript）
- `icon.svg` / `apple-touch-icon.png` / `og-image.png`: アイコンとリンクプレビュー用の画像
- `manifest.webmanifest` / `icon-192.png` / `icon-512.png` / `icon-maskable-512.png`: ホーム画面に追加（PWA）するための設定とアイコン
- `sw.js`: オフラインでも開けるようにするサービスワーカー（通信できるときは常に最新を読み込む）
